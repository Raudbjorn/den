# Milestone 3 roadmap: four plans

Spec: `docs/specs/0003-den-milestone-3.md` (ADR-0005, ADR-0006). The spec spans three subsystems, so it is built as four plans in order. Each plan ends with den working and every check green.

| # | Plan | Ships | Depends on |
|---|---|---|---|
| 1 | **Per-Repo `skip`** (`2026-11-21-m3-plan-1-skip.md`) | `[repos."OWNER/REPO"] skip` in config. `decide` falls through or withholds, honestly explained. Today's list hides Work Items whose only Next Step isn't tracked, and its empty state says so. | nothing |
| 2 | **Repo Survey foundation** | `SurveyTarget::Repo`, the one-Repo GitHub read (`repo.graphql`), per-Repo coverage for every Work Item source, cache format 13 keyed by Repo with the read-time guard. `Workspace::repo_at`, the startup rules, `den OWNER/REPO`, `--pick`, `--dump`/`--launch` targets. Today's UI opens straight into a Repo Scope, surveying only that Repo. | 1 (for `Policies`) |
| 3 | **Index, Sweep, recent, members** | `GitHubSource::index` (Repo lists with `description`/`pushedAt`, requests search), `LaneKind::Sweep` with cancellation and the rate-limit floor, per-Owner Sweep answers, `recent.json`, Landing Group member facts by number. | 2 |
| 4 | **The kit and the three screens** | `src/ui/kit/`, the Repo screen, Linear screen and workbench, the new keys, `TestBackend` snapshots (seam 3). Removal of Scopes, the sidebar, the tonal plates and the crepus templates. README, architecture and glossary updates. | 3 |

Plans 2–4 are written when their predecessor has merged, so that each argues from the code as it then is.
