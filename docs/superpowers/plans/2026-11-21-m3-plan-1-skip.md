# Milestone 3, Plan 1: per-Repo `skip` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a Repo stop tracking Next Step kinds with `[repos."OWNER/REPO"] skip = [...]` in `config.toml`. `decide` falls through or withholds, and explains it honestly. Work Items whose only Next Step isn't tracked leave den's list, and the empty state says so.

**Architecture:**
- `config` parses the `skip` lists into a new `domain::Skips`, carried inside `Policies` into `decide`.
- Pull Requests apply skips inside their rule table, so evaluation falls through to the next rule. Merge is withheld only after the Landing Group check, so a group member still "lands with" its Linear Issue.
- Issues, Branches and Runs have one candidate step each, so a post-pass in `decide_with` withholds it.
- Every withheld Decision records `not_tracked`. The App leaves those out of the list, and the empty state names what it left out.

**Tech Stack:** Rust 2024 (toolchain 1.96.1, pinned), `toml` 1.2 `Spanned`, `serde`, den's seam tests (`tests/support/{build,harness}`).

**Spec:** `docs/specs/0003-den-milestone-3.md`, section "Not tracking a flow (`skip`)", user stories 27–30. Roadmap: `docs/superpowers/plans/2026-11-21-m3-roadmap.md`.

## Global Constraints

- Errors are values: no `unwrap`/`expect`/`panic` in `src/` (clippy denies them). Tests may use them under the file's existing `#![allow(...)]` header.
- Next Step names in config and text are exactly `NextStep::label()` (`CONTEXT.md`'s spelling, case-sensitive): "Finish draft", "Resolve conflicts", "Fix CI", "Address review", "Review", "Merge", "Triage", "Implement", "Open PR", "Prune or revive", "Request review".
- "Start", "Land" and "Mark for release" are not skippable. Listing one is a config error.
- Config errors name the file, line and column (`ConfigError::Malformed`), like every existing config error.
- Repo names compare without case, as GitHub's do (`RepoId::same`).
- A skip never unblocks a step: rule preconditions (`merge_blockers`) are untouched.
- `tests/fixtures/milestone-1/decisions.json` must still match. New `Decision` fields are `#[serde(default, skip_serializing_if = "Option::is_none")]`.
- GitHub stays read-only (ADR-0002). Nothing here touches the network.
- Before each commit: `cargo fmt --all --check` and `cargo clippy --workspace --all-targets --locked -- -D warnings` pass.

## Review Focus

1. **An approved PR with failing checks in a Repo that skips Fix CI:** it must not get Merge. It has no Next Step and is `not_tracked` Fix CI, and the reason names both the skip and "checks failing". Pinned in Task 2, `skipping_fix_ci_never_makes_a_failing_pr_mergeable`.
2. **Two skipped kinds hold on one PR:** the earliest by precedence is recorded and both are noted, never just the first. Pinned in Task 2, `two_skipped_kinds_are_both_noted_and_the_earliest_recorded`.

5. **The selected Work Item stops being tracked after a refresh:** the selection moves to the first remaining row, without a panic or a stale index. Pinned in Task 4, `a_selected_work_item_that_stops_being_tracked_gives_way`.

/// The Next Step kinds each Repo doesn't track (`[repos."OWNER/REPO"] skip`,
/// spec 0003, "Not tracking a flow"). A Repo not listed tracks every kind.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Skips {
    by_repo: Vec<(RepoId, BTreeSet<NextStep>)>,
}

/// What a Repo without a `skip` list skips: nothing.
static NO_SKIPS: BTreeSet<NextStep> = BTreeSet::new();

impl Skips {
    /// `repo` doesn't track `steps`. Repos compare as GitHub compares names: a
    /// Repo already listed is replaced.
    #[must_use]
    pub fn with(mut self, repo: RepoId, steps: impl IntoIterator<Item = NextStep>) -> Self {
        let steps: BTreeSet<NextStep> = steps.into_iter().collect();
        match self.by_repo.iter_mut().find(|(listed, _)| listed.same(&repo)) {
            Some(entry) => *entry = (repo, steps),
            None => self.by_repo.push((repo, steps)),
        }
        self
    }

    /// The kinds `repo` doesn't track; empty when it isn't listed.
    pub fn for_repo(&self, repo: &RepoId) -> &BTreeSet<NextStep> {
        self.by_repo
            .iter()
            .find(|(listed, _)| listed.same(repo))
            .map_or(&NO_SKIPS, |(_, steps)| steps)
    }

    /// Whether `repo` has a `skip` list (compared as GitHub compares names).
    pub fn lists(&self, repo: &RepoId) -> bool {
        self.by_repo.iter().any(|(listed, _)| listed.same(repo))
    }
}
```

/// The `[repos."OWNER/REPO"]` tables' `skip` lists (spec 0003, "Not tracking
/// a flow"). Each value must be a skippable Next Step spelled as `CONTEXT.md`
/// spells it.
fn repo_skips(raw: BTreeMap<Spanned<String>, RawRepo>) -> Result<Skips, (Range<usize>, String)> {
    let mut skips = Skips::default();
    for (key, table) in raw {
        let key_span = key.span();
        let name = key.into_inner();
        let repo = match name.split_once('/') {
            Some((owner, repo)) if is_valid_login(owner) && is_valid_repo_name(repo) => {
                RepoId::new(owner, repo)
            }
            _ => {
                return Err((
                    key_span,
                    format!("{name:?} is not OWNER/REPO, such as \"octo/app\""),
                ));
            }
        };
        if skips.lists(&repo) {
            return Err((
                key_span,
                format!("{name} is configured twice (Repo names compare without case)"),
            ));
        }
        let mut steps = Vec::with_capacity(table.skip.len());
        for entry in table.skip {
            let span = entry.span();
            let label = entry.into_inner();
            let Some(step) = NextStep::from_label(&label) else {
                return Err((
                    span,
                    format!("{label:?} is not a Next Step: use one of {}", skippable_names()),
                ));
            };
            if !step.skippable() {
                return Err((
                    span,
                    format!("{label} belongs to Linear Issues, not to a Repo, so a Repo can't skip it"),
                ));
            }
            steps.push(step);
        }
        skips = skips.with(repo, steps);
    }
    Ok(skips)
}

/// The skippable Next Steps, quoted, in glossary order.
fn skippable_names() -> String {
    NextStep::ALL
        .into_iter()
        .filter(|step| step.skippable())
        .map(|step| format!("{:?}", step.label()))
        .collect::<Vec<_>>()
        .join(", ")
}
```

fn decide_all(observation: &Observation, policies: &Policies) -> Vec<Decision> {
    decide(observation, &Viewers::of(observation), policies, now())

fn pull_request<'d>(decisions: &'d [Decision], repo: &str, number: u64) -> &'d Decision {
    let id = WorkItemId::PullRequest {
        repo: repo_id(repo),
        number,
    };
    decisions
        .iter()
        .find(|d| same_work_item(&d.item.id, &id))
        .unwrap_or_else(|| panic!("no Decision for {repo}#{number}: {decisions:#?}"))
}

fn of_kind(decisions: &[Decision], kind: WorkItemKind) -> &Decision {
    decisions
        .iter()
        .find(|d| d.item.id.kind() == kind)
        .unwrap_or_else(|| panic!("no {kind:?} Decision: {decisions:#?}"))
}

/// Everything the Explanation says, in one string.
fn said(decision: &Decision) -> String {
    let e = &decision.explanation;
    format!(
        "{} | {} | {} | {}",
        e.winning_rule.as_deref().unwrap_or_default(),
        e.no_step_reason.as_deref().unwrap_or_default(),
        e.other_conditions.join(" | "),
        e.unknowns.join(" | ")
    )
}

fn assert_says(decision: &Decision, needles: &[&str]) {
    let text = said(decision);
    for needle in needles {
        assert!(text.contains(needle), "{needle:?} not in {text:?}");
    }
}

/// A Decision whose Next Step its Repo doesn't track (spec 0003), as no Next
/// Step. The kind's rule held, so the reason keeps its words; whoever owed
/// the step owes nothing now. A Linear Issue has no Repo and is never
/// withheld.
fn withhold_not_tracked(ctx: &Context<'_>, mut decision: Decision) -> Decision {
    let step = match (decision.next_step, decision.item.id.repo()) {
        (Some(step), Some(repo)) if ctx.skips(repo).contains(&step) => step,
        _ => return decision,

    decision.not_tracked = Some(step);
    decision.waiting_on = WaitingOn::Nobody;
    decision.waiting_reason = "no Next Step, so nobody owes one".to_owned();
    decision.unattributed = false;

/// An empty list never hides Work Items silently: the ones left out because
/// their Repo doesn't track their Next Step (`skip`, spec 0003) are named,
/// by kind and count.
fn with_not_tracked(state: &State<'_>, mut empty: EmptyState) -> EmptyState {
    let left_out: Vec<NextStep> = state
        .all_decisions
        .iter()
        .filter(|d| state.scope.scope.contains_decision(d))
        .filter_map(|d| d.not_tracked)
        .collect();
    if left_out.is_empty() {
        return empty;
    }
    let kinds: BTreeSet<NextStep> = left_out.iter().copied().collect();
    let kinds: Vec<&str> = kinds.iter().map(|kind| kind.label()).collect();
    let items = match left_out.len() {
        1 => "1 Work Item".to_owned(),
        n => format!("{n} Work Items"),
    };
    empty.detail = format!(
        "{} Not tracked here (skip in config.toml): {}, on {items}.",
        empty.detail,
        kinds.join(", ")
    );
    empty
}
